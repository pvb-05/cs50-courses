# CS50 Courses

This repository contains my work for Harvard University's CS50 courses, including exercises and projects from the introductory C track, the Python track, and SQL practice assignments.

## Overview

The project is organized into three main sections:

- `cs50/`: C-based problem sets and exercises from the original CS50 curriculum.
- `python/`: Python assignments, problem sets, and the final project.
- `sql/`: SQL labs and database-focused tasks.

This repo reflects a hands-on learning journey through core programming concepts such as algorithms, data structures, logic, problem solving, and database querying.

## Included topics

### C exercises

The `cs50` directory includes classic CS50 assignments such as:

- Caesar cipher
- Cash change-making
- Credit card validation
- Readability score
- Substitution cipher
- Speller and dictionary-based tasks
- Sorting and recovery algorithms

### Python exercises

The `python` directory includes assignments covering:

- Strings and data processing
- Input validation
- File handling
- Unit testing
- Data structures
- Command-line interfaces
- Final project: Pomodoro timer

### SQL exercises

The `sql` directory includes database practice using SQL queries and data analysis tasks based on real-world datasets.

## Final project

The Python final project in `python/project/` is a command-line Pomodoro timer application built with Python. It demonstrates key skills such as:

- CLI argument parsing
- Timers and countdown logic
- User interaction
- Audio and terminal notifications
- Testing with `pytest`

## Getting started

### C programs

Compile a C program with `gcc`:

```bash
gcc -o caesar caesar.c
./caesar
```

### Python programs

Run a Python script with:

```bash
python3 script.py
```

### SQL exercises

Open the relevant folder and run the SQL scripts using a database client or SQLite-compatible environment.
